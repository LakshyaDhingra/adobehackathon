# Demo walkthrough

The included MP4 uses outputs generated by this engine. It shows the source,
portrait/square/landscape adaptations, and the advanced 728×90 banner. It is a
rendered product walkthrough, not a recording of a live Adobe Express session.

For a live demonstration:

1. Run `python -m studio.app` and open http://localhost:5050.
2. Select **Core campaign**. Compare the source with its 1600×400 result.
3. Click **Story** and **Post**. Point out the product, headline, CTA and colour
   hierarchy surviving the changes in shape.
4. Select **Advanced campaign** at 728×90. Show that the copy is retained;
   acknowledge that 7 px is still small at native size. The missing holiday
   badge is an intentional starter-kit case, reported as a warning.
5. Download PNG and layout JSON, then export the four-size campaign archive.
6. In a signed-in Adobe Express developer session, sideload the add-on using
   `express-addon/README.md`. Click **Add as a new Express page** and verify
   the new page dimensions and that the original page remains unchanged.

Finale acceptance remains a real host check: CLI manifest validation and
mocked SDK tests do not substitute for step 6. Record that live insertion if
the jury expects the demo video to show Adobe Express itself.
